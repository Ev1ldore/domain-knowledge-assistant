# 星盒安装说明（虚构演示数据）
本文中的工具、命令和参数都是虚构测试资料，不对应真实产品。

## 星盒 2.4 的安装
星盒 2.4 演示版需要 Python 3.11 和至少 240 MB 可用磁盘空间。
星盒 2.4 的演示安装命令是 `starbox init --local`。安装结束后用 `starbox check` 检查工作目录。
安装成功时，检查结果显示 `workspace ready`。

## 星盒工作目录
星盒默认把笔记目录设为当前目录下的 `notes/`。
修改星盒笔记目录的方法是在 `starbox.ini` 中设置 `notes_dir`，然后重新启动星盒。
