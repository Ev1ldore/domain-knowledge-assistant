# 前端改造与验证记录

日期：2026-09-21。项目：桌面上的 `domain-knowledge-assistant`。

## 改造范围

基于现有 FastAPI 服务重新设计原生 HTML / CSS / JavaScript 页面，无新增前端运行依赖。修改 `static/index.html`、`static/style.css`、`static/app.js`，新增 `static/favicon.svg`。本次未修改 Python 服务、数据库结构、模型配置或原始教育版项目。

页面采用浅灰白与低饱和绿色，减少大面积装饰，将阅读回答和核对依据作为主要操作：

- 左侧工作区：新会话、历史搜索、问答与知识库管理导航、实时资料统计。
- 中部问答：欢迎提示、配置中的建议问题、流式状态、回答复制、输入字数及键盘操作。
- 右侧引用：点击回答编号打开对应真实片段，显示文件、章节、实际存在的页码及片段标识；历史引用失效时明确提示。
- 知识库管理独立页面：登录、文档与 FAQ 分开导入、索引数量及状态、重建与删除确认。
- 小屏幕使用导航抽屉和浮层引用，保留深浅主题、键盘焦点、减少动画偏好。

保留原浏览器会话存储键，现有会话可继续恢复；按服务返回的 instance_id 隔离不同实例。

## 与服务层的对应关系

| 功能 | 使用的现有接口 |
| --- | --- |
| 助手配置与资料统计 | GET /api/config、GET /api/status |
| 会话创建与历史 | POST /api/create_session、GET/DELETE /api/history/{session_id} |
| 流式回答 | WebSocket /api/stream |
| 管理员登录与退出 | POST /api/kb/login、POST /api/kb/logout |
| 文档列表与上传 | GET /api/kb/files、POST /api/kb/upload |
| 索引维护 | POST /api/kb/files/{id}/rebuild、DELETE /api/kb/files/{id} |
| FAQ 导入 | POST /api/kb/faq/import |

页面仅呈现服务返回的答案和引用，不在客户端生成业务答案。上传成功后显示等待解析与索引，只有 ready 状态显示为“可检索”。管理员令牌失效时回到登录界面。

## 实际验证

使用真实浏览器操作和同一套后端，另起 8082 端口并指定独立临时资料目录，未向原业务库导入测试内容。FAQ 和文档来自项目自带、明确标注虚构的星盒演示数据。

| 验证 | 实际结果 |
| --- | --- |
| 原会话兼容 | 8080 原有 E17 问答加载成功，保留答案及引用 |
| 空知识库 | 显示 0 份文档；实际提问后显示“尚未导入资料” |
| 登录失败/成功/退出 | 错误密码显示接口错误；正确登录展示管理操作；退出后恢复登录表单 |
| FAQ 文件导入 | 浏览器文件选择与提交，成功导入 2 条 FAQ，统计同步更新 |
| 文档上传与索引 | 上传 `星盒故障处理.md`，先显示“正在索引”，后变为“可检索”，实际生成 3 个片段 |
| FAQ 命中 | 实际提交“星盒工具是什么？”，返回正确 FAQ 答案与常见问答来源 |
| 文档问答 | 实际提交 E17 问题，经真实本地模型与检索服务返回处理步骤及 3 条真实引用 |
| 引用交互 | 点击编号 2，打开并定位含 `starbox index unlock` 的原文片段 |
| 刷新恢复 | 在 8082 刷新页面，恢复同一会话中的空库、FAQ、文档问答三轮历史 |
| 删除确认 | 显示具体文件及删除影响，取消后文件保留；本轮未确认执行删除 |
| 响应式 | 1360px 桌面布局及 390px 手机问答/管理布局；页面宽度等于 scrollWidth，无横向溢出 |
| 浏览器错误 | 隔离验证页检查到的 error 级日志为空 |
| JavaScript | `node --check static/app.js` 通过 |
| 后端未改 | 改造前后 Python 文件 SHA-256 比较一致 |

此处的真实文档问答调用现有本地模型服务，不是 Mock；但也不代表所有浏览器、所有文件格式、网络断连和模型故障分支都已逐一验证。深色主题、真实移动设备及完整无障碍读屏未做全面验收。服务层的既有验收及限制见 `VALIDATION.md`，不能用本轮前端验证替代。

## 使用与回退

按 README 的启动方式运行，访问 http://127.0.0.1:8080/ 。页面无需单独构建。

改造前的三个页面文件保存在 `.local/frontend-before-redesign/`；如需回退，仅复制其中的 `index.html`、`style.css`、`app.js` 到 `static/` 后刷新页面。备份及验证数据均属于本地运行资料，不应提交或打包为公开内容。
